# Spiele

Hier liegen spielespezifische Anleitungen.

Alles, was fuer ein bestimmtes Spiel grundsaetzlich gleich bleibt, gehoert hierhin:

- externe Tools
- Mod Manager
- Build- oder Launcher-Schritte
- Spielstart
- spielespezifische Troubleshooting-Hinweise

Szenarien unter `scenarios/` sollen diese Dateien nur noch verlinken und nicht doppelt erklaeren.

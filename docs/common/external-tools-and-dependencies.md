# Externe Tools und Abhaengigkeiten

Diese Datei erklaert nur die **gemeinsamen** Zusatztools rund um Archipelago.

Nicht gemeint sind:

- ROMs
- gekaufte Spiele
- Steam selbst

Spielespezifische Dinge liegen unter:

- [../games/README.md](../games/README.md)

## Gemeinsame Regel

Ihr braucht haeufig:

- die Multiworld-Plattform fuer YAML, Seed und Room
- plus spielespezifische Tools in den jeweiligen Spiel-Unterordnern

## Tool fuer mehrere Setups

### MultiworldGG Desktop Client

Verwendung:

- YAML-Dateien exportieren
- Seeds generieren oder ueber Website arbeiten
- Rooms erstellen
- Serverdaten verwalten

Download:

- <https://multiworld.gg/downloads/>

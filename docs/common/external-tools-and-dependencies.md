# Externe Tools und Abhaengigkeiten

Diese Datei erklaert nur die Zusatztools rund um Archipelago.

Nicht gemeint sind:

- ROMs
- gekaufte Spiele
- Steam selbst

## Gemeinsame Regel

Ihr braucht je nach Spiel nicht nur das Spiel selbst, sondern oft noch:

- ein Setup-Tool
- einen Mod Manager
- einen spiel-spezifischen Archipelago-Mod
- die Multiworld-Plattform fuer YAML, Seed und Room

## Tools fuer mehrere Setups

### MultiworldGG Desktop Client

Verwendung:

- YAML-Dateien exportieren
- Seeds generieren oder ueber Website arbeiten
- Rooms erstellen
- Serverdaten verwalten

Download:

- <https://multiworld.gg/downloads/>

## Tools fuer Super Mario 64

### SM64AP-Launcher

Verwendung:

- nimmt euren legalen `SM64`-ROM
- baut daraus eine spielbare Windows-PC-Version fuer Archipelago
- erzeugt die EXE, die ihr spaeter wirklich startet

Download:

- <https://github.com/N00byKing/SM64AP-Launcher/releases>

### MSYS2

Verwendung:

- Build-Umgebung unter Windows fuer `SM64`

Download:

- <https://www.msys2.org/docs/installer/>

Wichtig:

- nicht in einen Pfad mit Leerzeichen installieren

## Tools fuer Sonic Adventure DX

### SA Mod Manager

Verwendung:

- installiert und verwaltet Mods fuer `SADX`
- enthaelt spaeter `SAModManager.exe`
- darueber startet ihr das Spiel mit Archipelago-Mod

Download:

- <https://gamebanana.com/tools/15436>

### SADX_Archipelago

Verwendung:

- der eigentliche Archipelago-Zusatz fuer `SADX`

Bezugsweg:

- ueber die offizielle Setup-Seite beziehen, damit ihr bei der richtigen Release-Seite landet:
  - <https://multiworld.gg/tutorial/Sonic%20Adventure%20DX/setup_en>

## Nur bei Problemen oder Spezialfaellen

### .NET 8

Nur noetig, wenn der `SADX`-Guide oder eine Fehlermeldung explizit darauf hinweist.

### Universal Tracker

Im `SADX`-Guide genannt, aber fuer den einfachen MultiworldGG-Website-Flow meist nicht noetig.

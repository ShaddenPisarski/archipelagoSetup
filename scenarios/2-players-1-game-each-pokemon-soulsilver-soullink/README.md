# 2 Players, 1 Game Each, Pokemon SoulSilver SoulLink

Dieses Szenario ist fuer euren `Pokemon SoulSilver`-Run gedacht:

- 2 Spieler
- 1 Spiel pro Spieler
- `Pokemon SoulSilver`
- Windows-Emulator-Weg
- `SoulLink`
- `Nuzlocke`

## Kurzfassung

Das Ziel ist:

- beide Spieler haben dieselbe randomisierte `SoulSilver`-Datei
- beide Spieler spielen auf Windows am Emulator
- beide Spieler halten dieselben `SoulLink`- und `Nuzlocke`-Regeln ein

Wichtig:

- erst Emulator und Randomizer lokal vorbereiten
- dann randomisieren
- dann auf beiden PCs die gleiche randomisierte Datei starten

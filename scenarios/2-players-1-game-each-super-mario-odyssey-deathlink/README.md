# 2 Players, 1 Game Each, Super Mario Odyssey DeathLink

Dieses Szenario ist fuer euren `Super Mario Odyssey`-Challenge-Run gedacht:

- 2 Spieler
- 1 Spiel pro Spieler
- beide spielen `Super Mario Odyssey`
- 2 Slots in einem Room
- `DeathLink` als empfohlener Challenge-Modus

## Wichtige Vorwarnung

Der aktuelle `MWGG`-Guide sagt, dass `SMO` noch eine sehr fruehe Implementierung ist und Bugs wahrscheinlich sind.

Darum gilt fuer diese Repo-Doku:

- erst sauber testen
- dann erst langen Run planen

## Kurzfassung

Die 2 Standard-Slots fuer den ersten Run sind:

- `You_SMO`
- `Brother_SMO`

Die Repo-Empfehlung ist:

- `Switch` zuerst, wenn moeglich
- sonst `Suyu` oder ein aehnlicher Yuzu-Fork
- `Ryujinx` nur mit dem klaren Wissen, dass der Guide dort `Cannot Send Checks` nennt

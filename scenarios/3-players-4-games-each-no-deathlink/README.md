# 3 Players, 4 Games Each, No DeathLink

Dieses Szenario ist als Platzhalter fuer ein groesseres Multiworld-Setup gedacht.

## Zielbild

- 3 Spieler
- jeder Spieler hat 4 Spiele
- `Death Link` bleibt aus

## Erwartete Struktur

Ergebnis:

- 12 Slots
- 12 YAML-Dateien

Beispiel fuer einen Spieler:

- `Player1_Game1`
- `Player1_Game2`
- `Player1_Game3`
- `Player1_Game4`

## Hinweise

- ab dieser Groesse lohnt sich eine sehr saubere Slot-Benennung
- die Seed-Erstellung sollte zentral durch einen Organisator passieren
- zuerst ohne `Death Link` testen ist sinnvoll

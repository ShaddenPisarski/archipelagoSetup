# FromSoft Safe Co-op Overview

Dieser Bereich ist fuer euren gemeinsamen `FromSoft`-Run gedacht.

## Was hier enthalten ist

Aktuell sind drei Spiele vorbereitet:

- [Dark Souls Remastered](../2-players-1-game-each-dark-souls-remastered-coop/README.md)
- [Dark Souls III](../2-players-1-game-each-dark-souls-iii-coop/README.md)
- [Elden Ring](../2-players-1-game-each-elden-ring-coop/README.md)

## Was hier bewusst nicht enthalten ist

- `Dark Souls II`

Dieses Repo fuehrt `Dark Souls II` in diesem Track absichtlich nicht.

## Wichtiger Grundsatz fuer alle drei Spiele

Jedes Spiel hat:

- seinen eigenen Mod
- seine eigene `.ini`-Datei fuer das Passwort
- seinen eigenen Mod-Launcher
- seinen eigenen Spielordner unter Steam

Darum bekommt jedes Spiel hier einen eigenen Guide.

## Lesereihenfolge

1. passendes Spiel waehlen
2. dort die `README.md` oeffnen
3. dann den `BEGINNER-GUIDE.md` Schritt fuer Schritt abarbeiten

## Gemeinsame Regel fuer alle drei Spiele

Wenn ihr das Mod-Co-op spielen wollt:

- immer ueber den Mod-Launcher starten
- beide Spieler muessen dieselbe Spielversion haben
- beide Spieler muessen dieselbe Mod-Version haben
- dasselbe Session-Passwort eintragen

Wenn ihr normal solo oder vanilla spielen wollt:

- nicht ueber den Mod-Launcher starten

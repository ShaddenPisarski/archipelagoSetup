# 4 Players, 1 Game Each, No DeathLink

Dieses Szenario ist als sauberer Platzhalter fuer ein spaeteres konkretes Setup gedacht.

## Zielbild

- 4 Spieler
- jeder Spieler hat 1 Spiel
- `Death Link` bleibt aus

## Erwartete Struktur

Beispiel:

- `Player1_GameA`
- `Player2_GameB`
- `Player3_GameC`
- `Player4_GameD`

Ergebnis:

- 4 Slots
- 4 YAML-Dateien

## Wenn dieses Szenario spaeter ausgearbeitet wird

Dann sollte der Ordner mindestens enthalten:

- `README.md`
- `session-checklist.md`
- `room-link-template.txt`

Als Vorlage dient:

- [docs/templates/scenario-template.md](../../docs/templates/scenario-template.md)

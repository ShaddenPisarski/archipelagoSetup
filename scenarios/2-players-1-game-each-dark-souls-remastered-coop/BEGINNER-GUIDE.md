# Noob-Weg: Windows-Schritt-fuer-Schritt fuer Dark Souls Remastered Co-op

Wenn du einfach nur spielen willst, lies **nur diese Datei** von oben nach unten.

Ziel:

- du spielst `Dark Souls Remastered`
- dein Bruder spielt `Dark Souls Remastered`
- ihr seid im selben Mod-Co-op-Run

Wichtig:

- beide muessen dieselbe Spielversion haben
- beide muessen dieselbe Mod-Version haben
- beide muessen dasselbe Session-Passwort eintragen
- fuer diesen Run startet ihr **nicht** normal ueber Steam, sondern ueber den Mod-Launcher

## Was ihr vor dem Start braucht

Auf beiden Windows-PCs:

- `Dark Souls Remastered` ueber Steam
- Internet
- Steam gestartet

Extra-Tool:

- `Seamless Co-op` fuer `Dark Souls Remastered`

## Was ihr herunterladen muesst

1. Oeffne die Mod-Seite:
   - `https://www.nexusmods.com/darksoulsremastered/mods/899`
2. Lade die aktuelle Version von `Seamless Co-op` herunter.

Wichtig:

- beide Spieler muessen dieselbe Mod-Version nehmen

## In welcher Reihenfolge ihr es machen solltet

1. Spiel ueber Steam installieren
2. Mod herunterladen
3. Steam-Spielordner oeffnen
4. Mod in den `Game`-Ordner kopieren
5. Passwort in die `.ini` eintragen
6. Mod-Launcher starten
7. erst dann Host und Join im Spiel benutzen

## Den richtigen Spielordner oeffnen

Auf jedem PC:

1. Oeffne Steam.
2. Gehe in die Bibliothek.
3. Rechtsklick auf `Dark Souls Remastered`.
4. `Verwalten` anklicken.
5. `Lokale Dateien durchsuchen` anklicken.

Es oeffnet sich der Spielordner.

Suche dort den Unterordner:

```text
Game
```

## Mod an die richtige Stelle kopieren

1. Oeffne den heruntergeladenen Mod.
2. Entpacke ihn.
3. Kopiere die Mod-Dateien in den `Game`-Ordner von `Dark Souls Remastered`.

Danach solltet ihr dort den Mod-Launcher sehen.

Wichtig ist spaeter:

- `ds1sc_launcher.exe`

## Passwort eintragen

1. Oeffne im Spielordner den Ordner:

```text
SeamlessCoop
```

2. Oeffne die Datei:

```text
ds1sc_settings.ini
```

3. Trage dort euer gemeinsames Passwort ein.
4. Speichere die Datei.

Wichtig:

- beide Spieler muessen exakt dasselbe Passwort eintragen

## Das richtige Spiel starten

Fuer diesen Co-op-Run:

1. Doppelklicke:
   - `ds1sc_launcher.exe`
2. Warte, bis das Spiel startet.
3. Ruhe einmal an einem Bonfire.
4. Nutze danach die neuen Mod-Gegenstaende fuer Host und Join.

Nicht machen:

- den Run direkt ueber den normalen Steam-Start beginnen
- modded und normales Spiel wahllos mischen

## Erster Test

Bevor ihr ernsthaft startet:

1. Beide starten das Spiel ueber `ds1sc_launcher.exe`.
2. Beide pruefen, ob Steam offen ist.
3. Beide pruefen, ob das Passwort gleich ist.
4. Beide ruhen einmal an einem Bonfire.
5. Einer hostet.
6. Der andere joint.

Wenn das nicht klappt:

- Mod-Version vergleichen
- Passwort vergleichen
- pruefen, ob beide wirklich ueber `ds1sc_launcher.exe` gestartet haben

## Merksatz fuer dieses Spiel

Fuer Co-op:

- immer `ds1sc_launcher.exe`

Fuer normales Solo-Spiel:

- normal ueber Steam

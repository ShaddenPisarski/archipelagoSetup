# 2 Players, 1 Game Each, Dark Souls Remastered Co-op

Dieses Szenario ist fuer euren `Dark Souls Remastered`-Run gedacht:

- 2 Spieler
- 1 Spiel pro Spieler
- `Dark Souls Remastered`
- gemeinsamer Co-op-Run
- separater Mod-Launcher statt normalem Vanilla-Start

## Kurzfassung

Das Ziel ist:

- beide Spieler haben dieselbe Spielversion
- beide Spieler haben dieselbe Mod-Version
- beide tragen dasselbe Passwort ein
- beide starten den Run ueber `ds1sc_launcher.exe`

# 2 Players, 3 Games Each, MWGG Mixed Multiworld

Dieses Szenario ist fuer euren neuen echten `MultiworldGG`-Run gedacht:

- 2 Spieler
- 3 Spiele pro Spieler
- 6 Slots insgesamt
- `Pokemon Crystal`
- `Dark Souls Remastered`
- `Dark Souls III`

Das ist ein echter spieluebergreifender `MWGG`-Run:

- Items koennen zwischen Spielern und Spielen verschickt werden
- ihr sitzt in einem gemeinsamen Room
- jeder Slot hat seine eigene Welt

## Kurzfassung

Die 6 Standard-Slots fuer den ersten Run sind:

- `You_PokemonCrystal`
- `Brother_PokemonCrystal`
- `You_DSR`
- `Brother_DSR`
- `You_DS3`
- `Brother_DS3`

Wichtig:

- erst alle drei Spiele lokal vorbereiten
- dann alle 6 Optionen exportieren
- dann einen gemeinsamen `MWGG`-Seed erzeugen
- dann den Room starten
- dann verbinden

## DeathLink fuer dieses Szenario

Geplanter Standard in dieser Repo-Doku:

- `Dark Souls Remastered` mit `DeathLink`
- `Dark Souls III` mit `DeathLink`
- `Pokemon Crystal` als normaler `MWGG`-Slot ohne fest zugesagtes `DeathLink`

Wenn ihr spaeter bestaetigt, dass `Pokemon Crystal` in eurem aktuellen `MWGG`-Stand sauber `DeathLink` anbietet, koennt ihr das natuerlich angleichen.

## Kurzfassung

Ziel ist ein gemeinsamer Room mit diesen 4 Slots:

- `You_SM64`
- `You_SADX`
- `Brother_SM64`
- `Brother_SADX`

Wichtig:

- `1 YAML = 1 Slot`
- erst beide Spiele lokal zum Laufen bringen
- erst dann YAML-Dateien, Seed, Room und Verbindung

# 2 Players, 1 Game Each, SMZ3 Classic Challenge

Dieses Szenario ist fuer euren `SMZ3`-Challenge-Run gedacht:

- 2 Spieler
- 1 Spiel pro Spieler
- beide spielen `Super Metroid / ALttP Crossover`
- 2 Slots in einem Room
- klassischer Challenge-Stil

Das ist kein Komfort-Preset.

Das Ziel ist:

- fair
- klassisch
- nah an der ueblichen `SMZ3`-Erwartung

## Kurzfassung

Die 2 Standard-Slots fuer den ersten Run sind:

- `You_SMZ3`
- `Brother_SMZ3`

Wichtig:

- beide Spieler spielen ihre eigene `SMZ3`-Welt
- beide Welten liegen im selben `MWGG`-Room
- `DeathLink` wird hier nicht als Standard versprochen

# Session Checklist fuer den 2-Slot-SMZ3-Run

## Vor dem Seed

- `MultiworldGG` installiert
- `BizHawk` bereit
- beide Basis-ROMs bereit
- `BSNES`-Core eingestellt

## Slot-Namen

- `You_SMZ3`
- `Brother_SMZ3`

## Optionen

- `SMLogic = Normal`
- `Key Shuffle = None`
- `Goal = Defeat Both`
- `Accessibility = Full`

## Seed und Room

- beide `.yaml` hochgeladen
- beide Slots sichtbar
- beide `.apsmz3`-Dateien heruntergeladen

## Verbinden

- `.apsmz3` gestartet
- `SNI` laeuft
- `Connector.lua` geladen, falls noetig
- Server verbunden

## Test

- frueher Check gemacht
- Item kommt beim anderen Spieler an

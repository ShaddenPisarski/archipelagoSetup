# 2 Players, 1 Game Each, Elden Ring Co-op

Dieses Szenario ist fuer euren `Elden Ring`-Run gedacht:

- 2 Spieler
- 1 Spiel pro Spieler
- `Elden Ring`
- gemeinsamer Co-op-Run
- separater Mod-Launcher statt normalem Vanilla-Start

## Kurzfassung

Das Ziel ist:

- beide Spieler haben dieselbe Spielversion
- beide Spieler haben dieselbe Mod-Version
- beide tragen dasselbe Passwort ein
- beide starten den Run ueber `ersc_launcher.exe`

## Benennung

Die Ordner verwenden bewusst ein klares Schema:

- Anzahl Spieler
- Anzahl Spiele pro Spieler
- ob `DeathLink` an oder aus ist

So bleibt sofort erkennbar, welches Setup wofuer gedacht ist.

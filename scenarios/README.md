## Lesereihenfolge

Wenn du ein Szenario wirklich nachbauen willst:

1. passendes Szenario `README.md` oeffnen
2. dort zuerst den `BEGINNER-GUIDE.md` lesen
3. nur bei Rueckfragen die passende Datei unter `docs/games/` oeffnen

## Benennung

Die Ordner sind absichtlich direkt lesbar:

- Anzahl Spieler
- Anzahl Spiele pro Spieler
- Spiel oder Spielgruppe
- Modus wie `DeathLink`, `SoulLink` oder `coop`

So bleibt sofort erkennbar, welches Setup wofuer gedacht ist.

# 2 Players, 2 Games Each, SM64 Romhacks MWGG

Dieses Szenario ist fuer euren gemeinsamen `MWGG`-Run mit zwei `SM64`-Romhacks gedacht:

- 2 Spieler
- 2 Spiele pro Spieler
- `Super Mario Star Road`
- `SM 64 Last Impact`
- 4 Slots in einem Room

Die vier Standard-Slots sind:

- `You_StarRoad`
- `Brother_StarRoad`
- `You_LastImpact`
- `Brother_LastImpact`

## Was dieses Szenario meint

Dieses Setup meint **nicht**:

- dass ganze Welten zufaellig vertauscht werden
- dass jeder beliebige Objekt-Randomizer aktiviert wird

Dieses Setup meint:

- ihr spielt weiterhin die beiden bekannten Hacks
- `MWGG` verteilt wichtige Fortschrittsdinge zwischen euren 4 Slots

Standardmaessig sind hier vor allem wichtig:

- `Stars`
- `Keys`
- `Caps`
- `Cannons`

## Repo-Standard fuer den ersten Run

Fuer den ersten gemeinsamen Abend ist die Empfehlung:

- `Death Link = No`
- erst Stern-/Progressions-Sharing testen
- danach bei Bedarf einen zweiten Seed mit `Death Link = Yes`

## Wichtig

Diese Repo-Doku beschreibt bewusst nur den einfachen, offiziell gelisteten Pfad fuer:

- `Super Mario Star Road`
- `SM 64 Last Impact`

Der fortgeschrittene Custom-`json`-Weg fuer andere Hacks gehoert **nicht** in diesen Einsteigerpfad.

# Session Checklist fuer euren 4-Slot-SM64-Romhacks-MWGG-Run

## Vor dem Start

- `MultiworldGG` ist installiert
- `Luna's Project64` ist auf beiden PCs entpackt
- `connector_bizhawkclient_pj64.js` liegt im `Project64`-Scripts-Ordner
- der `stardisplay`-Join-Client ist bereit
- die originale `SM64`-Basis-ROM liegt bereit
- die fertige `Star Road`-ROM liegt bereit
- die fertige `Last Impact`-ROM liegt bereit
- Room ist erstellt

## Slot-Namen pruefen

- `You_StarRoad`
- `Brother_StarRoad`
- `You_LastImpact`
- `Brother_LastImpact`

## YAML-Einstellungen fuer den ersten Run

- `Hack to Use` stimmt pro Slot
- `Death Link = No`
- `Accessibility = Full`
- `Progression Balancing = Normal`

## Verbindungs-Reihenfolge

1. beide `Star Road`-Slots verbinden
2. einen fruehen Stern testen
3. beide `Last Impact`-Slots verbinden
4. noch einen fruehen Stern testen
5. dann erst alle 4 Slots offen lassen

## Pro Slot in Project64

1. richtigen Hack oeffnen
2. `Debugger -> Scripts`
3. `connector_bizhawkclient_pj64.js` starten
4. `stardisplay` oeffnen
5. `Archipelago -> Login`
6. passenden Slotnamen verbinden

## Erfolgszeichen

- Room zeigt alle 4 Slots
- keine Slot-Namen sind vertauscht
- Stern-/Progressions-Sends tauchen im Room oder Client auf

## Optional danach

- neuen Seed mit `Death Link = Yes` bauen
- `Death Link` nicht im allerersten Verbindungs-Test erzwingen

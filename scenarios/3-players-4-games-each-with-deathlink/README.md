# 3 Players, 4 Games Each, With DeathLink

Dieses Szenario ist als Platzhalter fuer ein groesseres Multiworld-Setup mit `Death Link` gedacht.

## Zielbild

- 3 Spieler
- jeder Spieler hat 4 Spiele
- `Death Link` ist in den gewuenschten Slots aktiviert

## Erwartete Struktur

Ergebnis:

- 12 Slots
- 12 YAML-Dateien

## Zusatzeffekt durch DeathLink

Wenn `Death Link` in vielen Slots aktiv ist:

- koennen Tode sehr schnell grosse Kettenreaktionen ausloesen

Darum sollte dieses Szenario spaeter klar dokumentieren:

- in welchen Slots `Death Link` wirklich an ist
- ob erst ohne `Death Link` getestet wird
- wie der erste Verbindungstest ablaufen soll
